# Proyecto 01 — Luz automática inteligente

Este es el material digital del Proyecto 01 de NUNAIT LABS.

## Archivos del proyecto

Aquí encontrarás:

- Código del ESP32
- Esquema de conexiones
- Plantilla para construir la carcasa con cartón
- Modelo para impresión 3D
- Fotografías del montaje
- Solución de problemas

Principiante absoluto.

No necesitas conocimientos previos de programación ni electrónica.

No conectes los componentes hasta haber comprobado el esquema de conexiones.

# Carcasa para impresión 3D

Si tienes acceso a una impresora 3D, aquí encontrarás una carcasa diseñada específicamente para el Proyecto 01.

## Archivos

- carcasa-nunait.stl

El modelo estará diseñado para los componentes exactos indicados en el libro.

Comprueba siempre que utilizas la misma versión del ESP32 y del sensor antes de imprimir.
